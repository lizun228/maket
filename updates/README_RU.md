# Обновление бота

Актуальная версия: **dialogue-synthesis-v3**, файл [lkp_bot_dialogue_v3.zip](lkp_bot_dialogue_v3.zip).

Внутри только программа и инструкции, без архива, базы доступов и `.env`.
Останови бот, сделай копию своей папки, затем скопируй обновление поверх программных файлов.
Сохрани свои `.env`, `knowledge.sqlite`, `access.sqlite`. Запусти `start_python312.bat`, затем `/new`.
`check_dialogue_windows.bat` проверяет реальные диалоги локальной Ollama и сохраняет TXT-отчёт.

75 тестов кода прошли; генерация в них имитируется. Настоящая Qwen в облаке не проверена.
`lkp_bot_source_only_v2.zip` — предыдущий режим с цитатами; для текущего исправления используй v3.
