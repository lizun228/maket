ИСПРАВЛЕННАЯ ВЕРСИЯ ДЛЯ WINDOWS

1. В BotFather отзови старый токен (/revoke) и получи НОВЫЙ.
2. Распакуй этот архив в отдельную папку полностью.
3. Запусти setup_windows.bat; откроется .env.
4. TELEGRAM_BOT_TOKEN = новый токен (не делись им).
5. ADMIN_TELEGRAM_IDS = числовой ID (не @ник). Получи у @userinfobot.
6. Для локальной модели:
   AI_PROVIDER=ollama
   AI_MODEL=qwen3:4b-instruct
   AI_API_KEY=
7. Сохрани .env в Блокноте.
8. Проверь в PowerShell: ollama list
   В списке должна быть скачанная модель. Проверь также: ollama run qwen3:4b-instruct
9. Запусти start_windows.bat; НЕ закрывай окно.
10. Напиши своему Telegram-боту /start.

Если не запускается, пришли текст ошибки из окна, но НЕ присылай токен или .env целиком.
Внимание: этот архив содержит базу обсуждений из группы, не публикуй её без разрешений.
