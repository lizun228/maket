# Telegram-бот по реставрации ЛКП: версия для России

Бот отвечает ученикам по базе переписки «Выпускники ПрайдМастер», используя локальный поиск по архиву. Встроено ограничение доступа; дневной лимит регулируется строкой DAILY_QUESTION_LIMIT в .env. **Это не обучение модели на всех сообщениях, а подбор связанных фрагментов плюс генерация ответа.**

## Сначала

1. Установи Python 3.11+ для Windows с python.org (поставь галочку Add Python to PATH).
2. Распакуй ZIP целиком, не запускай программу из окна ZIP.
3. Дважды кликни `setup_windows.bat` и заполни `.env`.
4. Дважды кликни `start_windows.bat`; не закрывай консоль, пока бот должен отвечать.
5. Напиши своему боту в Telegram `/start` и вопрос, например «Почему возникает просадка после ИК-сушки?»

**Секреты:** никому не отправляй файл `.env` и API-ключи. Если присылал токен посторонним, перевыпусти его у @BotFather.

## Вариант 1: платно в рублях, с ИИ (рекомендуем)

Сайт https://proxyapi.ru/ ; документация https://proxyapi.ru/docs/quickstart
Создай аккаунт и API-ключ, пополни баланс картой РФ или СБП. Минимальная сумма у сервиса не заявлена; можно тестировать с небольшим бюджетом, например 100–300 ₽. Запросы тарифицируются по токенам, без абонплаты.

В `.env`:

    TELEGRAM_BOT_TOKEN=твой_токен_от_BotFather
    ADMIN_TELEGRAM_IDS=твой_ID
    AI_PROVIDER=proxyapi
    AI_API_KEY=твой_ключ_ProxyAPI
    AI_MODEL=deepseek/deepseek-chat

Можно выбрать другие модели из каталога https://proxyapi.ru/models/ — тарифы отличаются. Оплата за генерацию и текст архивных выдержек, передаваемых в API. Если ты не имеешь права передавать историю переписки стороннему сервису, не выбирай этот режим.

## Вариант 2: бесплатно без ИИ (самая быстрая проверка)

В `.env`:

    TELEGRAM_BOT_TOKEN=твой_токен_от_BotFather
    ADMIN_TELEGRAM_IDS=твой_ID
    AI_PROVIDER=offline

`AI_API_KEY` может оставаться пустым. Бот ищет и отправляет фрагменты переписки, **не формулирует интеллектуальный ответ**. Это удобно, чтобы проверить Telegram, доступы и качество поиска, не тратя деньги и не передавая архив за пределы компьютера.

## Вариант 3: бесплатно с локальным ИИ (Ollama)

1. Установи Ollama для Windows: https://ollama.com/download/windows .
2. Открой PowerShell и выполни: `ollama pull qwen3:4b-instruct`. Будет загружена языковая модель.
3. Убедись, что Ollama работает (обычно фоновое приложение).
4. В `.env`:

    TELEGRAM_BOT_TOKEN=твой_токен_от_BotFather
    ADMIN_TELEGRAM_IDS=твой_ID
    AI_PROVIDER=ollama
    AI_MODEL=qwen3:4b-instruct

`AI_API_KEY` не нужен. Скорость и качество ответов зависят от оперативной памяти, процессора и видеокарты. При слабом ПК может работать медленно; база архива не уходит в облачную модель, если Ollama работает локально. В примере используется локальная модель. Для доступа ученикам компьютер должен быть включён.

## Команды

- `/start` — приветствие / ID при отсутствии доступа
- `/id` — узнать свой ID
- `/status` — проверить доступ
- `/grant 123456789 180` — админ выдаёт доступ на 180 дней
- `/revoke 123456789` — админ закрывает доступ
- `/stats` — число активных учеников и запросов

Обязательное условие: в `ADMIN_TELEGRAM_IDS` должен стоять **твой** Telegram ID. Администраторы имеют доступ к вопросам и без `/grant`. Новые ученики передают свои ID после оплаты.

## Замечания

- Поиск основан на тексте архива; фото и видео в архиве не обрабатываются.
- Участники исходной группы могут содержать ошибки. Бот не заменяет технологические карты и практическое обучение.
- Данные о доступе учеников хранятся в `access.sqlite` рядом с ботом. Не удаляй этот файл при обновлении.
- Не отправляй текст переписки стороннему API без необходимых разрешений участников и законных оснований.
- Перед запуском для платных учеников проверь на нескольких технических вопросах, что качество ответа тебя устраивает.
- Полноценное тестирование ответа от ProxyAPI/Ollama и Telegram требует твоих ключей и компьютера; offline-тесты проверяют только локальные функции.

### Если запуск не удался

Прочитай сообщение в открывшемся окне. Если Python не находится, переустанови Python с Add Python to PATH. Если у ProxyAPI недостаточно баланса, пополни его. Если не отвечает Ollama, проверь, что она запущена и модель скачана. Не присылай скриншот со строками ключей.

## Если раньше возникала ошибка `_pydantic_core` / `DLL load failed`

В этой версии для Ollama **не используется библиотека OpenAI SDK** и `pydantic_core`.
Старые установленные пакеты удалять не нужно: они больше не импортируются.

1. Распакуй **новый** ZIP в **новую папку**.
2. В новой папке запусти `setup_windows.bat`, внеси **новый** Telegram-токен и **числовой** ID.
3. Проверь `AI_PROVIDER=ollama` и `AI_MODEL=qwen3:4b-instruct`.
4. Запусти `start_windows.bat`.
5. В Telegram отправь `/start`, затем свой вопрос.

Предупреждения pip про `Scripts not on PATH` и обновление pip сами по себе запуску бота не мешают.
